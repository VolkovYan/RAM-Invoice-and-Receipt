# RAM Solutions Invoice & Receipt Studio

Open `index.html` in Chrome, Safari, or another modern browser. The supplied `RAM Final Logo.png` file is used throughout the app and documents. The app runs locally and stores edits in that browser on this computer.

## Use

1. Choose **Invoice** or **Receipt**.
2. Edit customer details, document number and date, item descriptions, quantities, prices, and the other fields in the left panel.
3. Use **+ Add line item** for additional rows. Subtotal, balance, and receipt total update automatically.
4. Choose **Print / Save PDF**. The invoice is formatted as A4 portrait; the receipt is formatted as A5 landscape. In the print dialog, choose **Save as PDF** to create a PDF file, or select a printer.

The supplied `MMS Invoice.pdf` and `MMS Receipt.pdf` remain unchanged as references. **Save** and automatic saving keep the current editable document data in browser storage. This app does not upload the document or its data.
